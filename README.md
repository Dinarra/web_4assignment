## Description

This project is a multi-page website about creating user-friendly forms with HTML and Bootstrap 5. It shows how to use HTML5 built-in validation and Bootstrap validation classes (`is-valid`, `is-invalid`). Every page has a navigation bar (navbar) that links to all tasks.

## Pages

| Task | File | Description |
| --- | --- | --- |
| Task 0 | `index.html` | Simple contact form: Name, Email, Message, Submit button, all fields with `<label>` |
| Task 1 | `task1.html` | Form with HTML5 validation (`required`, `type`, `minlength`, `maxlength`) |
| Task 2 | `task2.html` | Contact form with Bootstrap form classes, grid system, placeholders and helper text |
| Task 3 | `task3.html` | Bootstrap validation styles (`is-valid`, `is-invalid`) with feedback messages, checked with JavaScript |
| Task 4 | `task4.html` | Registration form: names, email, password and confirm password, gender (radio), hobbies (checkbox), country (select), Submit and Reset buttons. Responsive Bootstrap grid, HTML5 validation and Bootstrap feedback |

## Technologies

- HTML5
- Bootstrap 5.3 (CDN)
- JavaScript

## How to run

1. Clone the repository:
   ```
   git clone https://github.com/Dinarra/web_4assignment.git
   ```
2. Open the project folder.
3. Open `index.html` in a web browser (internet connection is needed to load Bootstrap from CDN).
4. Use the navigation bar to move between the tasks.
